# Perit's Little Adventure

Perit（ペリット）と一緒に迫りくる壁をかいくぐり、星を集めるフラッピングゲームです。

**170BPMの音楽に同期**させたリズミカルなゲームです。

## 🎮 遊び方

### 基本操作

- **スペースキー押し** → 羽ばたいて上昇
- **スペースキー離す** → 下降
- 上下に操って迫りくる上下の壁の間を通り抜ける

### ゲーム進行

- ⭐️ **星を取る** → +4点
- 🚪 **壁を通る** → +1～31点（壁穴の狭さで変動）
- 壁穴は **スコアが増えるほど狭くなる** → 難易度上昇
- 🎯 **1000点越え** → 神になれます！

## 💡 Tips

- `D`でデバッグ表示ON/OFF（壁番号・Gap表示）が可能です。

- 上昇も下降も加速度となっているので、押し続けたり離しっぱなしにするとあっという間にゲームオーバーになります。コツは、音に合わせて小刻みに押すことです。

## 🛠️ 技術スタック

- **p5.js** 1.7.0 - ゲーム描画・フィジックス
- **p5.sound** - 音声管理
- **HTML5 Canvas** - レンダリング

## 🎵 ゲーム設計

- **BPM**: 170 （Youtubeで「flight of the bumblebee」でヒットした動画を適当にごにょごにょしました💦）
- **拍子**: 4/4
- **壁生成タイミング**: 音楽の4拍ごと
- **フレームレート**: 60fps

音声再生時間を基準にしているため、PCの負荷が変動してもゲームテンポはズレません。(多分…)

## 📊 スコア計算

```
基本ギャップ = 400px
ギャップ減少 = スコア × 0.5px
最小ギャップ = 100px

壁のポイント = (400 - 現在のギャップ) / 10 + 1
星のポイント = 4
```

難易度が上がるほどスコア獲得量も増える設計となっています。
