# 🌟 Perit's Little Adventure

Perit（ペリット）と一緒に迫りくる壁をかいくぐり、星を集めるフラッピングゲームです。

**170BPMの音楽に同期**させたリズミカルなゲームです。

## 🎮 遊び方

### 基本操作
- **スペースキー長押し** → 羽ばたいて上昇
- **スペース離す** → 下降
- 迫りくる上下の壁の間を通り抜ける

### ゲーム進行
- ⭐️ **星を取る** → +4点
- 🚪 **壁を通る** → +1～31点（壁穴の狭さで変動）
- 壁穴は **スコアが増えるほど狭くなる** → 難易度上昇
- 🎯 **1000点越え** → 神になれます！

## 💡 Tips

| キー | 機能 |
|------|------|
| `スペース` | 羽ばたき（上昇） |
| `D` | デバッグ表示ON/OFF（壁番号・Gap表示） |

## 🎵 ゲーム設計

- **BPM**: 170 （Youtubeで「flight of the bumblebee」でヒットした動画を適当にごにょごにょしました💦）
- **拍子**: 4/4
- **壁生成タイミング**: 音楽の4拍ごと
- **フレームレート**: 60fps

音声再生時間を基準にしているため、PCの負荷が変動してもゲームテンポはズレません。(多分…)

## 🐛 デバッグ機能

ゲーム中に **D キー** を押すと：
- 各壁の **通し番号** (#1, #2, ...) を表示
- **壁穴の幅（Gap）** をピクセル単位で表示

難易度調整やテスト時に活用できます。

## 📊 スコア計算

```
基本ギャップ = 400px
ギャップ減少 = スコア × 0.5px
最小ギャップ = 100px

壁のポイント = (400 - 現在のギャップ) / 10 + 1
星のポイント = 4
```

難易度が上がるほどスコア獲得量も増える設計となっています。
